# Концепт витрины

`index.html` — макет нового дизайна витрины, `checkout.html` — форма данных
пассажиров. Оба файла самодостаточные, открываются в браузере без сборки.
Кнопка «Купить у партнёра» на витрине открывает форму с выбранным рейсом:
маршрут, дата, время, число пассажиров и категория льготы передаются в адресе. Данные о рейсах, местах и отзыв в нём
вымышленные, покупка и подписка не подключены (об этом говорит плашка вверху).

На GitHub Pages публикуется по адресу `/design/` рядом с основной витриной.

Что в макете:

- поиск, фильтры, календарь мест и подписка работают на демо-данных;
- форма проверяет право на льготу по возрасту на дату вылета, формат паспорта
  и свидетельства о рождении, показывает экран проверки перед оплатой;
  данные никуда не отправляются, оплата пройдёт в кассе партнёра;
- светлая и тёмная тема по настройке системы;
- анимации на Motion 11 (ванильная сборка с jsDelivr), при
  `prefers-reduced-motion` отключаются, без библиотеки страница работает так же;
- адаптив проверен на экранах от 320 до 2560 px, включая альбомную ориентацию.

Перед запуском в бою: разместить шрифты, иконки Phosphor и Motion у себя
вместо CDN, заменить демо-данные на выдачу `webapp.py`, убрать плашку и отзыв.
Если форма будет собирать данные по-настоящему, сайт становится оператором
персональных данных (152-ФЗ): уведомление Роскомнадзора, политика обработки,
хранение в России. Сейчас данные должна собирать касса партнёра.
