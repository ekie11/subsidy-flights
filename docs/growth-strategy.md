# Стратегия развития (19 августа 2026)

1. **Категории льгот у текущего партнёра** (дёшево): пенсионеры, инвалиды,
   сопровождающие, многодетные. Коды категорий уже известны (см. PROJECT_CONTEXT.md).
   Источник: https://www.biletdv.ru/pages/Subsidirovannie-Aviabilety-Aeroflot-2026-dlya-molodegi-pensionerov-invalidov
2. **Telegram-бот как основной канал роста**: закрывает TODO по подпискам,
   выполняет условие партнёра (опрос только по спросу), сам по себе канал
   привлечения (уведомления пересылают в семейные чаты). Делать раньше или
   параллельно с доработкой сайта.
3. **География**: Калининград, Юг/Кавказ, Крайний Север, Поволжье — свои
   программы субсидий и свои перевозчики (ИрАэро, Смартавиа, Ред Вингс, ЮТэйр…),
   значит отдельный партнёр и API. Только после устойчивых продаж с БилетДВ.
   Источник: https://movens.ru/info/post_39_19407/
4. **B2B/B2G**: аналитика спроса для министерств ДФО, АНО по человеческому
   капиталу, гранты. Позже — реклама локального турбизнеса.
5. **Смежный транспорт** (гипотеза): РЖД, паромы Сахалин/Курилы.

Последовательность: боевой PartnerID + бот → категории льгот → покрытие ДФО
по реестру Росавиации → white label (порог 100 продаж/мес) или новый регион.
