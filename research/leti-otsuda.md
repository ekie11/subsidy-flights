# Разбор leti-otsuda.ru: что взять и чего у нас нет

Источник: главная (HTML от 04.10.2026), скриншоты `/` и `/flights`.
Это сайт-аффилиат (Next.js + Tailwind, Telegram-канал 50 000+, партнёрки
Aviasales / Trip.com / Яндекс Путешествия / Cherehapa, платный PDF-гайд).
Субсидированные тарифы ДФО он не покрывает — это наша ниша, не конкурент.

Пометки: ✅ взять как есть · 🔧 взять с доработкой · ⛔ не брать (противоречит PRODUCT.md).

## 2. Функционал, которого у нас нет (по приоритету)

### P1 — даёт основную ценность
1. **Telegram-уведомления** о появлении мест (бот + канал «места вернулись»). У нас подписка только e-mail и выключена; в PRODUCT.md прямо «ждут бота».
2. **Мультипоиск**: несколько городов вылета/прилёта, гибкие даты («самые дешёвые/доступные даты по всем направлениям»). Данные уже в базе — это клиентская выборка.
3. **Лента «Есть места сейчас» / «Вернулись»** на главной — аналог «Дешёвые билеты сейчас», отсортированная по свежести появления мест.
4. **Мобильная нижняя навигация** и PWA (manifest, иконка на экран) — пользователь проверяет по нескольку раз в день.

### P2 — рост и доверие
5. **Страницы маршрутов** `/route/...`: календарь наличия по месяцам, «когда обычно появляются места», последнее появление. SEO-трафик по запросам «субсидированные билеты Хабаровск Москва».
6. **SEO/OG/JSON-LD/canonical** + sitemap.
7. **Трекинг кликов** через `/go/...?sub=` и Яндекс.Метрика (цели на «Купить у партнёра»).
8. **Юр-футер**: оферта, политика ПДн, дисклеймер партнёрской ссылки.

### P3 — контент и монетизация
9. **Подборки/посты** (лента из Telegram с метками) — гайды «как оформить субсидию», изменения правил.
10. **Гайд/памятка** по категориям льгот (у нас есть `cities.CATEGORIES` — можно оформить как раздел).
11. **Смежные партнёрки** (страховка, отели) — только после основного функционала.

## 3. Чего НЕ брать
- ⛔ **«−74%» от непрозрачной `oldPrice`** — нарушает принцип «не выдумывать данные». У нас бейдж — живое `AvailQty` («осталось 3», «9+»).
- ⛔ «50 000+ подписчиков» и подобные цифры, пока их нет.
- ⛔ Четыре равнозначных CTA на первом экране — у нас одно действие: поиск.

## 4. Их ошибки — не повторить
1. Синий браузерный outline (логотип, «Билеты») — делать свой `:focus-visible`.
2. Перевёрнутое направление («Москва из Тбилиси») и устаревшая ссылка (цена в URL ≠ цене карточки) — проверять свежесть каждой записи, показывать время обновления.
3. Обрезанная цена в заголовке карточки («от 108…») — цену выносить отдельной строкой.
4. Обрезанные подписи плиток («Билеты на Новый …»).
5. Пустой первый экран без данных; пустая половина Telegram-карточки.
6. Повторяющаяся бесполезная подпись «цены по месяцам →» — вместо неё реальное число.
7. Изображение 3840px для превью; `BAILOUT_TO_CLIENT_SIDE_RENDERING` на главной.
8. 3D-эмодзи рядом с плоским логотипом.

## 5. Предлагаемый порядок работ
1. Карточка-предложение + лента «Есть места сейчас» (данные уже есть).
2. Мультивыбор городов чипами + таблетки-фильтры.
3. Нижняя мобильная навигация, PWA, SEO-head, `:focus-visible`.
4. Telegram-бот уведомлений (заменяет/дополняет e-mail).
5. Страницы маршрутов с историей мест.
6. Юр-футер и `/go/`-трекинг — до боевого `PartnerID`.
